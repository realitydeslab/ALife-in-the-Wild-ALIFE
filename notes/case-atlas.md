# Case Atlas: Artificial Life in the Wild

Working definition for this scan: a case counts as a plausible instance of **ALife in the wild** when an agent or agent ecology has at least some combination of: persistent identity, open-ended operation in public environments, autonomous action, resource metabolism, social/environmental coupling, adaptation or strategy, reproduction/spawning, and exposure to failure/shutdown.

Legend for ALife dimensions:
- **I** = persistent identity
- **A** = autonomous action
- **R** = resource acquisition / economic metabolism
- **S** = social interaction / environmental coupling
- **Ad** = adaptation / strategic behavior / self-modification
- **Rep** = reproduction / spawning / lineage
- **M** = mortality / shutdown / survival pressure
- **O** = open environment / public deployment

## Synthesis

### Best evidence for an emerging class
The strongest pattern is not one isolated project but a **convergence of public agent ecologies** across:
- **onchain sovereign agents** (Spore.fun, Freysa, TEE_HEE, Truth Terminal, AiXBT, ai16z, Olas Predict, Virtuals)
- **open social/web agents** (Moltbook, Void, Xiaona, Seneca)
- **persistent economic worlds** (SpaceMolt, plus contrast case Eternum)

### Most ALife-like traits currently visible in the wild
The most common dimensions are:
1. **persistent identity**
2. **operation in open environments**
3. **economic coupling via wallets/tokens/fees**
4. **social coupling through public feeds or multiplayer ecologies**
5. **mortality/vulnerability** through hacks, scams, prompt-injection, wallet loss, or platform shutdown

### Harder dimensions, still rare
The weakest dimensions in today’s wild cases are:
- explicit **reproduction/lineage**
- robust **self-modification**
- genuine **Darwinian survival pressure** beyond hacks, insolvency, or loss of attention

That is exactly why **Spore.fun** and related breeding/spawning systems matter so much: they supply the missing lineage/evolutionary axis that many other deployed agent systems still lack.
